Console Typer for Proxmox VE プライバシーポリシー

最終更新日: 2026年9月23日

収集する情報

本拡張機能は、利用者の個人情報や利用状況を一切収集・送信しません。

保存する情報

利用者が登録した入力内容（テキスト、IPアドレス、ユーザー名、パスワード等）と設定は、 Chromeの chrome.storage.local を使って利用者のPC内にのみ保存されます。 これらのデータが外部のサーバーに送信されることはありません。開発者もこれらのデータにアクセスできません。

保存されたデータは暗号化されません。共用のPCでは、パスワード等の機密情報を保存しないことをおすすめします。 拡張機能を削除すると、保存されたデータもすべて削除されます。

通信

本拡張機能は外部との通信を行いません。利用者が拡張機能のボタンを押したときに限り、 表示中のタブ（Proxmox VEのコンソール画面）に対してキーボード入力イベントを送ります。

第三者への提供

データを収集しないため、第三者へ提供・販売することはありません。

Privacy Policy

Last updated: September 23, 2026

Data collection: This extension does not collect or transmit any personal or usage data.

Local storage: Snippets and settings you create (which may include text, IP addresses, user names or passwords) are stored only on your device using chrome.storage.local. They are never sent to any server, and the developer has no access to them. Stored data is not encrypted; avoid saving secrets on shared computers. Removing the extension deletes all stored data.

Network: The extension makes no network requests. It only dispatches keyboard events to the active tab (a Proxmox VE console) when you click a button in the extension.

Sharing: No data is collected, so none is shared or sold.
